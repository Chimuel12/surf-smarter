# SurfSmarter

Dónde y cuándo ir a surfear desde Stuttgart: ranking de destinos por mes, nivel y tiempo disponible; olas, viento y agua en directo con previsión de 7 días; calendario de temporadas; y ficha de viaje (tren regional, tren o avión, precios orientativos, neopreno y gente).

App web instalable (PWA), sin build: `index.html`, `sw.js` y `manifest.webmanifest`.

Datos de olas y viento: [Open-Meteo](https://open-meteo.com/) (Marine API y Forecast API, CC BY 4.0). Los datos de viaje y temporada son orientativos.
